# QuizMaster (Python / Streamlit)

A gamified multiple-choice quiz app built entirely in Python using Streamlit — category/difficulty selection, timer, scoring with streak bonuses, result review, and a form to add your own questions.

## Project Structure

```
quizmaster_streamlit/
├── quizmaster.py       # The entire app
└── requirements.txt    # Python dependencies
```

## Installation

Requirements: Python 3.9+

```bash
cd quizmaster_streamlit
pip install -r requirements.txt
streamlit run quizmaster.py
```

Then open the URL it prints (usually http://localhost:8501) in your browser.
